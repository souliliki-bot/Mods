# Обман и доверие — Minecraft Bedrock (Android)

Отдельная реализация режима для Minecraft Bedrock. Исходный Fabric-мод Java Edition в корне репозитория не изменяется.

## Совместимость

- Целевая версия: **Minecraft Bedrock 1.26.30.5**.
- Минимальная версия движка в манифестах: **1.26.30**.
- API: `@minecraft/server 2.8.0` и `@minecraft/server-ui 2.1.0`.

## Установка на Android

1. Открой [последнюю сборку Bedrock](https://github.com/souliliki-bot/Mods/actions/workflows/bedrock.yml).
2. Выбери последний запуск со статусом **Success**, открой раздел **Artifacts** и скачай `LeaveOrSteal-Bedrock-Android`.
3. Распакуй архив и открой файл `.mcaddon` через Android, выбрав Minecraft.
4. В настройках мира включи Behavior Pack и связанный Resource Pack.
5. Для сетевой игры каждый участник должен подключиться к этому миру; аддон включается на стороне мира-хоста.

## Уже реализовано в Bedrock-переносе

- Сенсорное GUI-меню, приватные приглашения и очередь 1 на 1.
- Девять раундов по умолчанию, быстрый матч на 3 раунда, «Хаос» и «Высокие ставки».
- Роли владельца и выбирающего, заявления, выбор «Оставить» / «Украсть».
- Семь классов наград с весами выпадения: обычные, железные, алмазные, незеритовые, еда/зелья, редкие и легендарные.
- Способности «Щит» и «Проницательность» — каждая один раз за матч.
- Случайные события: удвоенная награда, раскрытие предмета и сундук-ловушка.
- Сундук-ловушка — настоящий блок сундука с обычным интерфейсом/анимацией открытия и звуком; варианты исхода: обычная награда, редкая награда, яд, взрыв без разрушения блоков или пустой сундук. Сундук автоматически удаляется и защищён от ломания.
- Ставки предметами: предмет из основной руки помещается в escrow; победитель решения получает ставки. Незавершённые ставки сохраняются в динамических свойствах мира и возвращаются при следующем входе.
- Финальная PvP-дуэль для 1 на 1 и 2 на 2; смерть, выход или отключение в финальной дуэли считаются поражением/сдачей.
- Одиночный матч против ИИ с финальным враждебным мобом. Моб получает усиление, сопротивление и экипировку, подобранную по добытому снаряжению.
- Настраиваемые точки арены, телепортация, восстановление здоровья и голода.
- Постоянная статистика побед, поражений, раундов, краж и сохранённых предметов; базовые достижения и звания за серии побед/активность.
- Награды выдаются в инвентарь; если места нет, предмет выпадает рядом. Лук и арбалет дополнительно получают 16 стрел.

## Команды

Все команды вводятся в чат с префиксом `!los`.

| Команда | Назначение |
|---|---|
| `!los menu` | Открыть сенсорное меню |
| `!los start` | Начать матч с другим игроком |
| `!los start bot` или `!los bot` | Матч против ИИ |
| `!los quick` | Быстрый матч на 3 раунда |
| `!los chaos` | Хаос: повышенная частота событий |
| `!los highstakes` | Удвоенные ставки/награды |
| `!los join` | Очередь 1 на 1 |
| `!los team` или `!los 2v2` | Командный матч 2 на 2 (нужны 4 игрока) |
| `!los invite <ник>` | Пригласить игрока |
| `!los accept <ник>` / `!los decline <ник>` | Принять / отклонить приглашение |
| `!los claim <текст>` | Заявление владельца |
| `!los keep` / `!los steal` | Оставить / украсть награду |
| `!los ability shield` | Одноразовый щит владельца |
| `!los ability insight` | Одноразовое раскрытие предмета выбирающему |
| `!los wager` | Поставить предмет из основной руки |
| `!los mob fight` / `!los mob leave` | Сразиться с финальным мобом / отказаться |
| `!los stats` | Статистика и достижения |
| `!los loot` | Информация о наградах |
| `!los status` | Фаза и номер раунда |
| `!los leave` | Выйти или сдаться |
| `!los setarena1` / `!los setarena2` | Сохранить точки арены |
| `!los settings` | Настройки раундов, телепортации, здоровья и голода |
| `!los rounds <1-30>` | Число раундов |
| `!los classes` / `!los pool` | Классы предметов и веса |
| `!los class <класс>` | Включить/отключить класс |
| `!los weight <класс> <0-100000>` | Изменить вес класса |

## Что ещё требует отдельного этапа

Это уже существенный перенос игровых систем, но нельзя честно утверждать, что он полностью идентичен Java-моду и проверен на реальном Android-устройстве. Bedrock использует другой API и другой набор сущностей/предметов. Следующими этапами остаются:
- тестирование всех сценариев непосредственно в Minecraft 1.26.30.5 на Android и исправление обнаруженных API/игровых несовместимостей;
- расширенная настройка пулов предметов, включая классификацию сторонних Bedrock-предметов;
- расширенная панель достижений/званий и визуальная настройка арены;
- дополнительные режимы «Выживание» и «Предатель», уникальные босс-фазы и балансировка 2 на 2.

CI проверяет синтаксис JavaScript, корректность JSON-манифестов и создание `.mcaddon`. Это не заменяет запуск игры на Android: финальное подтверждение игровых механик возможно только после тестирования в самом Bedrock.
