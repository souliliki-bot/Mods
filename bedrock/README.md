# Обман и доверие — Minecraft Bedrock (Android)

Отдельный Bedrock-перенос исходного Fabric-мода. Java-версия в корне репозитория не изменяется.

## Совместимость

- Целевая версия Minecraft Bedrock: **1.26.30.5**.
- Минимальная версия движка в манифестах: **1.26.30**.
- Зависимость: стабильный `@minecraft/server 2.8.0`, поставляемый с Bedrock 1.26.30.

## Установка на Android

1. Скачай артефакт `LeaveOrSteal-Bedrock-Android` из последнего успешного запуска [сборки Bedrock](https://github.com/souliliki-bot/Mods/actions/workflows/bedrock.yml).
2. Распакуй скачанный ZIP-архив и открой файл `.mcaddon` через Android, выбрав Minecraft.
3. Дождись импорта, затем включи Behavior Pack и связанный Resource Pack в настройках мира.
4. Для игры с другом оба игрока должны находиться в одном мире с включённым аддоном.

## Команды в игровом чате

- `!los help` — справка.
- `!los start` — начать матч с другим игроком, который находится в мире.
- `!los start bot` — одиночный матч против простого ИИ.
- `!los highstakes` — матч с удвоенными наградами.
- `!los keep` / `!los steal` — оставить или украсть награду.
- `!los claim <текст>` — заявление владельца.
- `!los shield` — одноразовая защита от кражи.
- `!los insight` — одноразовое раскрытие предмета.
- `!los stats` — текущая статистика сессии.
- `!los leave` — выйти из матча.

## Текущий статус

Это прототип игровой логики на стабильном Bedrock Script API. Реализованы старт матча на двух игроков или против простого ИИ, девять чередующихся раундов, случайные награды, решения keep/steal, заявления, способности и режим удвоенных наград.

Пока не перенесены: полноценное GUI-лобби и приглашения, физический сундук-ловушка с анимацией, постоянная статистика, escrow ставок, арена/телепортация, продвинутые случайные события и финальная PvP/моб-дуэль. Эти механики будут добавляться следующими этапами.
