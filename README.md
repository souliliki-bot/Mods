# Обман и доверие (Leave or Steal)

**Minecraft Java 1.21.1 · Fabric · Java 21**

## Первая техническая основа

Проект содержит исходный Fabric-мод и CI-сборку. После установки на сервер доступны команды:

- `/leaveorsteal help` — справка.
- `/leaveorsteal status` — состояние текущей реализации.
- `/leaveorsteal classes` — семь классов сундуков.
- `/leaveorsteal items <namespace>` — число предметов из указанного namespace (например, `minecraft` или идентификатор другого мода).

Список предметов берётся из реестра сервера, поэтому команда видит зарегистрированные предметы установленных модов.

## План реализации

1. Основа Fabric и серверные команды.
2. Конфигурация классов и пулов предметов сторонних модов.
3. Серверная машина состояний матча, таймеры и защита от повторного выбора/дюпа.
4. GUI семи сундуков, тайные предметы и решения «ОСТАВИТЬ» / «УКРАСТЬ».
5. Режим бота с уровнями сложности и блефом.
6. Арена, финальная экипировка и PvP.

Матчи, GUI, бот и арена пока не реализованы — не используйте эту раннюю сборку как готовую мини-игру.
