# Обман и доверие (Leave or Steal)

Minecraft Java Edition 1.21.1 · Fabric · Java 21

Мод для мини-игры на двух игроков или игрока против бота.

## Основная идея

Участники играют на арене с двумя отдельными комнатами и семью сундуками-классами. В каждом сундуке находится предмет соответствующей категории. Владелец видит содержимое своего сундука и описывает его сопернику — честно или блефуя. Слушающий игрок принимает решение:

- **ОСТАВИТЬ** — предмет остаётся у владельца сундука.
- **УКРАСТЬ** — предмет получает принимающий решение игрок.

После хода роли меняются. После девяти раундов игроки получают время на экипировку, затем начинается PvP-дуэль.

## Режимы

- Игрок против игрока.
- Игрок против бота: лёгкая, средняя и сложная сложность; бот умеет блефовать.

## Семь классов сундуков

1. Обычные предметы.
2. Железное снаряжение.
3. Алмазное снаряжение.
4. Незеритовое снаряжение.
5. Зелья и еда.
6. Редкие предметы.
7. Легендарные предметы.

## Предметы из других модов

Предметы выбираются из реестра предметов, доступного серверу. Конфигурация позволит включать и исключать namespace модов и отдельные идентификаторы предметов. Классификация будет настраиваемой: предметы сторонних модов не всегда можно надёжно отнести к классу автоматически.

Для игры на сервере соответствующие моды должны быть установлены на сервере и клиентах. Предметы передаются как ItemStack, чтобы сохранять компоненты/данные, зачарования и прочие поддерживаемые свойства.

## Безопасность и архитектура

- Сервер авторитетен: только сервер выбирает предметы, хранит тайные предметы и принимает решения.
- Тайный предмет не отправляется клиенту соперника до раскрытия.
- Проверка участника, текущего хода и повторных нажатий.
- Предметы блокируются от ручного перемещения и дюпа на время матча.
- Обработка выхода участника и отмены матча.
- Базовое общение — обычный чат; интеграция с voice chat не обязательна.

## Статус

Начальная спецификация. Функциональность будет добавляться поэтапно; сборка и игровые сценарии должны проверяться до публикации готового JAR.
