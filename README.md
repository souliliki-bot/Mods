# Обман и доверие (Leave or Steal)

**Minecraft Java 1.21.1 · Fabric · Java 21**

## Текущая реализация

Проект содержит исходный Fabric-мод и CI-сборку. На сервере доступны команды:

- `/leaveorsteal help` — справка.
- `/leaveorsteal join` — встать в очередь на матч 1 на 1.
- `/leaveorsteal status` — состояние матча и роль.\n- `/leaveorsteal loot` — показать только свои выигранные предметы до конца матча.
- `/leaveorsteal claim <текст>` — заявление владельца о тайном предмете.
- `/leaveorsteal keep` — оставить предмет владельцу.
- `/leaveorsteal steal` — забрать предмет себе.
- `/leaveorsteal leave` — покинуть очередь или матч.
- `/leaveorsteal classes` — семь классов предметов.
- `/leaveorsteal pool` — количество предметов в каждом пуле.
- `/leaveorsteal items <namespace>` — число предметов указанного мода.
- `/leaveorsteal reloadconfig` — перезагрузить конфигурацию (требуется уровень прав 2).

## Сохранение наград

- При отключении игрока незавершённый матч завершается, а накопленные награды сохраняются для отсутствующего игрока.
- При штатной остановке сервера незавершённые матчи переводятся в очередь наград; предмет текущего раунда также сохраняется за текущим владельцем.
- Награды записываются в `data/leave-or-steal-rewards.json` и автоматически выдаются игроку при следующем входе.
- При заполненном инвентаре остаток предметов выбрасывается рядом с игроком.

Сохранение выполняется при штатной остановке сервера; аварийное завершение процесса не гарантирует сохранность последних изменений.

## Предметы и конфигурация

Список предметов берётся из реестра сервера, включая зарегистрированные предметы установленных модов. При первом запуске создаётся файл `config/leave-or-steal.properties`.

Поддерживаются:
- включение namespace через `enabledNamespaces` (или `*` для всех);
- исключение namespace через `excludedNamespaces`;
- исключение отдельных ID через `excludedItems`;
- исключение предметов по фрагментам ID через `excludedPathKeywords` (по умолчанию исключаются яйца призыва, командные блоки, барьеры, структурные блоки, джигсо-блоки, отладочная палка и книга знаний);
- ручное назначение класса через ключи вида `item.minecraft:diamond_sword=DIAMOND_GEAR`.

В раундах сервер выбирает предмет из доступных пулов. Его название и категория видны только текущему владельцу; соперник получает только заявление владельца. После решения предмет сохраняется за победителем раунда и выдаётся в инвентарь после девятого раунда.

## Что ещё не реализовано

- GUI и физические комнаты с разделительным стеклом.
- Автоматическое строительство/телепортация на арену.
- Бот и три уровня сложности.
- Таймеры раундов и полноценная обработка отключения с сохранением уже выигранных предметов.
- Финальная экипировка на отдельной площадке и PvP-дуэль.
- Голосовой чат.

Это ранняя играбельная основа для проверки механики через команды, а не законченная мини-игра. Перед использованием на публичном сервере требуется тестирование.
